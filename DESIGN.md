# Framewise design direction

A working curation desk for travel photographers returning with hundreds of RAW frames.
Photography dominates: near-black canvas, charcoal panels, warm off-white type and quiet sage selections.
System sans-serif for controls; a restrained serif title for the collection. No external font requests.
Fixed 220px navigation on desktop, compact navigation on narrow screens. A bounded paginated grid uses
consistent image wells without distorting aspect ratios. Detail viewer reserves a large dark image stage
and a readable metrics column; on mobile this becomes a vertically scrolling sheet.
Visible keyboard focus, labelled icon actions, persistent selection borders, explicit loading/errors,
and reduced-motion support. No colourful metric cards, stock imagery, invented AI claims or gradients.

Highlights adds two focused review tabs. Competition finalists use restrained gold/silver/bronze rules
and a larger #1 frame; Flickr Standouts use a small star. Badges sit below photography. Display model
outputs and preview measurements separately from heuristic rank scores. Side-by-side comparison uses
matched image wells and a compact evidence table. At narrow widths, finalists stack and controls wrap;
manual photo search and comparison use keyboard-accessible, focus-trapped modal sheets.
